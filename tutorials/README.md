## Conformance notes

- **Standalone carrier (ST1–ST8):** the primary path performs no clone, repository install or repository import. Section 2 embeds the repository's 3 modules (`metrics.py`, `pipeline.py`, `samples.py`) verbatim in dependency order (each tagged `metadata.dimer.embedded_module`; the only rewrite makes the weights root working-directory-relative, and package-relative imports are removed). Section 3 carries the three snapshot manifests inline and asserts each against the module's constants before staging.
- **Parity (PAR1–PAR4):** `tests/test_notebook_parity.py` and `tools/validate_release_assets.py` fail when the carried modules, the inline manifests or the inline pins differ from the repository, or when the notebook is not byte-identical to the generator's output.
- **Model acquisition (MOD1–MOD9):** staging fetches only absent manifest entries, from the Hugging Face Hub at the immutable revisions; verification re-hashes every entry; every file is safetensors or JSON/text; nothing is unpickled and no remote code runs.
- **Stages (§4.1):** `fetch_sample_dataset` / `load_byod_dataset` → `validate_dataset` (masks attached, refusal probes) + `dataset_manifest` → seeded stratified split (36 / 12 / 12) → `encode_prompts` + `release_prior` → frozen `evaluate`, `generate`, `score_inpainting_preservation`, `score_generations` with the mean-fill floor and the original-photograph ceiling (baseline) → `adapt` → the same measurements on identical inputs (evaluation) → a new caption inpainted into held-out photographs (inference) → `save_artifact` → `from_artifact` + `import_prompt_cache` with the parity assertion.
- **Conditioning:** `evaluate` and `adapt` give the UNet the same nine-channel input as `diffusers` inference: noisy latents, masked latents and the keep-mask channel (`unet_keep_mask`, 1 = keep), while records keep the repository convention (255 = repaint).
- **Score semantics (UNC1–UNC4):** CLIP scores are scaled similarities, not probabilities; kept-region PSNR measures the MoVQ round trip, not edit quality; the denoising loss is the training objective. No threshold is set and no calibration is claimed.
- **Baselines and evidence (EVAL6/EVAL10):** the frozen model is measured before adaptation on the same seeded latents, noise, masks and generation seeds; a mean-colour fill is the no-model floor and the original photograph the ceiling. Every metric is labelled sample-sanity evidence from 12 held-out photographs with no dispersion estimate.
- **Split integrity (SPL1–SPL8):** seeded and stratified per species, no photograph in two splits (`check_split_disjoint`), validation selects the epoch, and the test photographs are used only for the final comparison. In BYOD mode the split is by caption.
- **BYOD (DAT10–DAT19):** `USE_BYOD` defaults to `False`, so the default path never opens an upload dialog. When enabled, user records flow through the same validation, encoding, baseline, adaptation, evaluation, inference, export and reload cells after a re-run from Section 3, which rebuilds an unadapted pipeline; a guard in Section 6 refuses to measure an already-adapted pipeline as the baseline. A row without a `mask` gets the centre mask, and the cell reports how many did. Refusals name the row, the id and the file.
- **Guided layer (GDL1–GDL15, §3.5):** the opening names the intended learner, the GPU requirement and **How to use this notebook** (Run all, form fields, Infrastructure cells, section tags, predictions and sample answers), a **Roadmap** and an **Input → Model/System → Output** contract, observable learning objectives and a collapsible **Glossary**. Sections 4, 6, 7, 8 and 10 ask the learner to **Predict before running**; Sections 6 and 8 state the **Question tested**; **Expected result** / **What to notice** notes follow each principal stage; five **Check your reasoning** boxes and the conclusion scaffold carry sample answers. Section 10 is the optional **Predict → Change one thing → Run → Observe → Explain** activity on the mask size, running after every required output is written (`RUN_ACTIVITY` turns it off). Sections 1–3 are **[Engineering]** infrastructure: their cells are collapsed (`cellView: form`, `jupyter.source_hidden`) and the install and model cells are titled `# @title Infrastructure: …`; the carried module cells stay byte-identical to the package, so they are collapsed by metadata only. Every numbered section is tagged **[Concept]**, **[Evaluation practice]** or **[Engineering]**. A **Troubleshooting** table and a **Conclude with evidence** scaffold close the notebook, and the prose says "notebook" throughout.
- `tools/validate_release_assets.py` performs source validation only. It does not satisfy the clean-runtime execution requirement; a release review must confirm that a recorded clean run in `docs/release-verification.md` matches the notebook revision under review before the status is promoted to `Release-grade`.
